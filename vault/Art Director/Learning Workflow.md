# Learning Workflow

## Retrieve

Read [[Art Director Home]], then find the relevant records through [[Project Knowledge Map]] and [[Learning Index]]. Search by game, subject, mechanic, and related terms. Consult the evidence behind a note before applying it beyond its original scope.

## Capture

1. Decide whether the finding is reusable and whether a canonical record already exists.
2. Update the existing record or create one in the location specified by Home. Use [[Learning Template]] for new vault learnings.
3. Record the source, date, scope, observed evidence, interpretation, confidence, and limitations separately.
4. Add a link to [[Learning Index]] for a new vault note or a useful existing record. Avoid duplicating full source material.
5. Update agent memory only when the finding changes future operating behavior. Update specialist instructions only when warranted by the user's feedback or approved workflow.

## Revise

An appealing reference does not demonstrate performance. Keep untested ideas marked as hypotheses. Use the existing performance library's promotion criteria for measured learnings. Preserve previous evidence when a finding changes; explain what supersedes it and why. Conflicting findings should retain their distinct contexts until evidence resolves them.

Capture happens during authorized project work. Notes are not automatically imported from chats, apps, or external accounts.
