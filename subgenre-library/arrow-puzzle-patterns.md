# Arrow Puzzle Ad Patterns

## Scope

Patterns observed in Arrow-family puzzle ads. Apply only when the target game has directional clearing, blocked paths, sequencing, or a similar mechanic.

## Observed patterns

### Directional release

The player taps arrows in an order that allows them to exit without colliding with blocked paths.

### Visible obstruction

The viewer can see why a move is unavailable or risky. A blocked arrow, red flash, lost heart, or failed stamp makes the rule understandable.

### Shape-based maze

The arrow board forms an animal, face, object, symbol, or decorative silhouette. This creates novelty and a memorable visual identity.

### Controlled failure

The player makes an obvious wrong move and receives a visible penalty. The penalty should invite correction rather than make the game seem unfair.

### Satisfying release

Arrows leave the board with clear direction, motion, sound, and board-clearing progress.

### Challenge and relaxation lanes

Use challenge, IQ, hearts, and failure for mastery-oriented concepts. Use calm pacing, clean boards, and ASMR feedback for relaxation-oriented concepts. Do not mix them without a deliberate emotional reason.

## Useful variation axes

- Animal or object silhouette
- Neon, monochrome, toy-like, or natural material treatment
- Challenge versus relaxation
- Real gameplay versus hybrid framing
- Failure penalty versus clean solving
- Close-up interaction versus full-board reveal
- Fast escalation versus methodical clearance

## Accuracy checks

- Are arrows actually directional?
- Are blocked paths and exit rules real?
- Are the displayed shapes and levels available?
- Are IQ, heart, offline, ad-free, and level-count claims verified?
- Does the ad show real gameplay or clearly label a creative demonstration?

The accepted production direction is the [Arrow Level Studio](../arrow-level-studio/index.html): source vector → sampled color grid → independent same-color orthogonal paths → solver → deterministic preview/export.
