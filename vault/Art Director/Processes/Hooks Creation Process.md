# Hooks Creation Process

The production sequence and phase-one scope are agreed below. Detailed creation rules and approval gates are still under development.

## Workspace and agreed direction

- Draft images use the selected Higgsfield model's smallest supported resolution. Video drafts remain 480p and final video remains 720p; the other production rules are unchanged (owner update, 2026-10-29).

- Emotional engagement is the central intent of every hook. Art Director writes an original story and visual directions from the brief before requesting Higgsfield mocks; each story must be meaningful and serve the brief's purpose. The canonical requirements are in the linked production rules.

- [Production rules](../../../Hooks/rules/production-rules.md) record the owner's draft/final resolution, model-cost, attempt, duration, and scoring requirements. Read them before generation. Game DNA is N/A during phase one; equal scoring weights and retry-count semantics are working interpretations, not explicit owner requirements.

- Reuse the existing Art Director visual skills as the shared visual foundation. Hooks does not need a separate visual skill set. Hook-specific rules cover storytelling, sequencing, and approval gates; universal visual feedback stays in the existing skills and feedback ledger.

- [Hooks workspace](../../../Hooks/README.md) contains the folder map and production organization.
- Original user-created videos go in project `Hooks/source/video-references/`, optionally grouped by game. These are the initial learning material.
- Phase one uses supplied knowledge and an incoming Hook Analyzer brief without Game DNA; game accuracy remains unassessed.
- Art Director develops the story and prompts, then reviews and approves each production stage itself.
- Intended sequence: Higgsfield first-frame mock -> 4–5 storyboard images -> smaller-scale draft video -> upscale and final check -> Mixer handoff.
- [Hook Analyzer skill](../../../skills/hook-analyzer/SKILL.md) defines the upstream analysis and brief-writing role. It hands evidence-backed briefs to Art Director; Mixer will be developed later.
- New reference analyses and hook learnings live in `Hooks/reference-analysis/` and `Hooks/knowledge/`; link these canonical records from the vault.
