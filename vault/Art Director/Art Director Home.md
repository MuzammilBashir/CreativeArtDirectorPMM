The shared starting point for Art Director knowledge, references, and reusable learnings.

- [[Learning Template]] — structure for a new reusable learning.

## Before creating or advising

1. Identify the game or brand, task, and available evidence.
2. Read the project memory and root operating skill using the knowledge map.
3. Search the vault and relevant project libraries for the topic, game, and related terms. Open matching notes and their source records.
4. Load the applicable specialist skills; apply standing owner feedback for visual work.
5. State which evidence supports important decisions and which ideas remain hypotheses.

## Where knowledge belongs

| Knowledge | Canonical location |
| --- | --- |
| Agent operating rules and durable memory | Project `AGENTS.md`, `CLAUDE.md`, and `agent-memory/art-director-memory.md` |
| Specialist procedures and owner art feedback | Project `skills/`, with Claude-compatible copies in `.claude/skills/` |
| Approved general advertising principles | Project `ad-bible/` |
| Game, genre, and subgenre observations | Existing project genre/subgenre libraries; game-specific records in the appropriate project library |
| Measured experiment results | Project `performance-library/` |
| Original sources and reference provenance | Project `source/` and existing reference records |
| Visual directions and asset reviews | Project `visual-directions/` |
| New cross-topic learnings without an existing home | Vault `Learnings/`, linked from [[Learning Index]] |
| Proposed workflows | Vault `Processes/`, clearly marked draft until agreed |

Existing records are linked, not silently copied or migrated. The vault does not yet contain all existing project knowledge. External project files may open outside Obsidian; only notes inside this vault participate in its internal note graph.

Future sessions must follow project instructions to retrieve this knowledge. There is no background watcher or automatic source import.
