# Puzzle Ad Patterns

## Scope

Patterns for mobile puzzle-game ads. These are not universal rules; they apply after the Ad Bible and should be adapted to the specific mechanic, audience, and objective.

## Common player motivations

- Mastery and problem solving
- Completion and order
- Curiosity
- Relaxation
- Satisfying progress
- Correcting an obvious mistake

## Common creative territories

### Challenge and mastery

Show an understandable mistake, escalating consequence, and a puzzle the viewer believes they can solve.

### Oddly satisfying

Show smooth, ordered interaction, tactile feedback, clean progress, and a satisfying completion state.

### Novelty transformation

Use an unusual puzzle shape, object, character, or transformation to earn attention before demonstrating the mechanic.

### Stress relief

Position the game as calm, low-pressure, offline, or interruption-free only when those claims are verified.

## Common hook patterns

- Gameplay begins mid-action
- Challenge text over a visible puzzle
- Near-miss or blocked move
- Unusual puzzle silhouette
- Board transformation
- Immediate tactile clearance
- Before-and-after board state

## Common proof patterns

- Show the input and result together.
- Keep the board centered and readable.
- Use a cursor or hand only when it clarifies interaction.
- Show several small progress moments.
- Reveal increasing complexity without hiding the local rule.

## Common risks

- Fake gameplay or unavailable levels
- Confusing rules
- Too much decorative framing
- Failure that looks random
- Claims such as IQ improvement without evidence
- Relaxation claims paired with stressful pacing
- Visual complexity that hides the board
